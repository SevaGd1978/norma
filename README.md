# Погрузка — калькулятор норм

Веб-калькулятор норм погрузки труб и фасонки в фуру по таблицам:

- `Нормы погрузки трубы.xlsx`
- `Нормы погрузки ФАС.xlsx`

## Онлайн

**Сайт:** https://shiny-nougat-35bc00.netlify.app  
**Пароль:** `My-Drop-Site`

Чтобы убрать пароль и закрепить сайт навсегда — claim в Netlify (ссылка в PR, действует ~1 час после деплоя).

Постоянный вариант через GitHub Pages: после merge в `main` включите
**Settings → Pages → Source → GitHub Actions**.  
Адрес: `https://sevagd1978.github.io/norma/`

## Запуск локально

```bash
python3 -m http.server 8080
```

## Возможности

- Совместный расчёт труб и фасонки в одной фуре
- Доли загрузки суммируются: `ceil(трубы/норма + отводы/норма + НОП/норма + концевой/норма)`
- Визуализация смешанной загрузки
- Автоподбор диаметра фасонки по оболочке трубы
- Просмотр исходных таблиц
