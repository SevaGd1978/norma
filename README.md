# Погрузка — калькулятор норм

Веб-калькулятор норм погрузки труб и фасонки в фуру по таблицам:

- `Нормы погрузки трубы.xlsx`
- `Нормы погрузки ФАС.xlsx`

## Запуск

Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
python3 -m http.server 8080
```

Затем откройте http://localhost:8080

## Возможности

- Норма погрузки труб по диаметру оболочки и длине (1,8 / 2 / 2,2 м)
- Норма погрузки фасонки (отводы, НОП, концевой элемент)
- Расчёт числа фур по количеству к отгрузке
- Просмотр исходных таблиц
