# Погрузка — калькулятор норм

Веб-калькулятор норм погрузки труб ППУ и фасонки в фуру.

## Данные

- **Трубы ППУ** — открытые таблицы производителей (ГОСТ 30732): борта 2,3–2,45 м, коники 1,2 / 1,5 / 1,8 м, оболочки ПЭ / ОЦ  
  Источники: 1нзти, СКС, ЗТИ Цивилизация и др.
- **Фасонка** — из исходной таблицы заказчика

## Возможности

- Совместный расчёт труб и фасонки в одной фуре
- Выбор ПЭ/ОЦ и высоты коников
- Доли загрузки: `ceil(трубы/норма + отводы/норма + НОП/норма + концевой/норма)`
- Визуализация смешанной загрузки (SVG-фура)
- Просмотр исходных таблиц
